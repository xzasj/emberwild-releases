# 雾烬 · 幸存者

Windows 版末日生存游戏。

[下载安装器](https://github.com/xzasj/emberwild-releases/releases/latest/download/EmberwildSetup.exe) · [查看最新版本](https://github.com/xzasj/emberwild-releases/releases/latest)

首次运行安装器，选择游戏文件夹，点击“安装并开始”。无需安装 GitHub，也无需注册账号。

已经装过 Unity 版的玩家，请选择原来包含 Emberwild.exe 的游戏文件夹，沿用其中的 UserData 存档。

以后通过桌面图标启动，会提示可用更新，仅下载所需变化内容；网络暂时不可用时可继续玩已安装版本。首次安装仍需下载完整游戏。

存档和设置保留在玩家自己的电脑中，不会上传到这里。安装目录的 UserData 文件夹请保留。
